# 📜 Code of Conduct — SecureGen

This project follows a respectful, inclusive, and collaborative philosophy.  
All contributors, maintainers, and community members are expected to follow this Code of Conduct.

---

# 🤝 Our Pledge

We pledge to make participation in SecureGen a harassment‑free experience for everyone, regardless of:

- age  
- body size  
- visible or invisible disability  
- ethnicity  
- gender identity or expression  
- level of experience  
- nationality  
- personal appearance  
- race  
- religion  
- sexual identity or orientation  

We commit to fostering an open, welcoming, diverse, and healthy community.

---

# 🌱 Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful and considerate  
- Giving and gracefully accepting constructive feedback  
- Focusing on what is best for the community  
- Showing empathy toward others  
- Helping newcomers and encouraging learning  

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments  
- Public or private intimidation  
- Publishing others’ private information  
- Disruptive or aggressive behavior  
- Any conduct that could harm the project or its community  

---

# 🛠 Responsibilities of Maintainers

Project maintainers are responsible for:

- clarifying standards of acceptable behavior  
- taking appropriate action in response to unacceptable behavior  
- removing or rejecting contributions that violate this Code  
- temporarily or permanently banning contributors if necessary  

Maintainers must apply this Code fairly and consistently.

---

# 🚫 Scope

This Code of Conduct applies to:

- the project repository  
- GitHub Issues and Pull Requests  
- Discussions  
- community spaces  
- any interaction related to the project

# 🧭 Enforcement

Violations may result in:

- a warning  
- temporary or permanent ban  
- removal of contributions  
- escalation to GitHub if necessary  

The maintainers’ decisions are final.
