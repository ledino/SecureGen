# 🛠 Responsibilities

Maintainers are responsible for:

- Reviewing and merging contributions  
- Ensuring code quality and security  
- Maintaining cross‑platform compatibility  
- Managing the release process  
- Enforcing the Code of Conduct  
- Responding to security reports  
- Guiding contributors and new maintainers  

---

# 🚀 Becoming a Maintainer

New maintainers may be added based on:

- consistent, high‑quality contributions  
- demonstrated understanding of SecureGen’s architecture  
- adherence to project standards (tests, docs, PS5/PS7 parity)  
- positive and constructive community interactions  

Maintainers are added by consensus as described in `GOVERNANCE.md`.
