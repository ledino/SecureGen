# 🐛 Bug Reports

If you believe you found a bug, please open an Issue using the template:

👉 `New Issue → Bug Report`

Before submitting:

- Ensure you are using the **latest version**  
- Include reproduction steps  
- Include PowerShell version (`$PSVersionTable`)  
- Include OS information  
- Include SecureGen version (`(Get-Module SecureGen).Version`)  

This helps maintainers diagnose the problem quickly.

# ✨ Feature Requests

If you want to propose a new feature or improvement:

👉 `New Issue → Feature Request`

Please include:

- The problem you want to solve  
- Why the feature is useful  
- Example syntax or usage  
- Alternatives you considered

# 🛠 Troubleshooting

If something doesn’t work:

1. Check the documentation  
2. Check the Troubleshooting guide  
3. Try with the latest version  
4. Test on PowerShell 7 if possible  
5. Open a Discussion if unsure  
6. Open a Bug Report if confirmed
